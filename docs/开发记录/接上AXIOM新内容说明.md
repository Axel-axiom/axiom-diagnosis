# 接上 AXIOM 0.14 的模型和卡片

## 能认出的物质
- 新增：V₃Si、LaBeH₈（化学式），甲酸、乙酸（醋酸、冰醋酸）、丙酸、氯乙酸、二氯乙酸、三氯乙酸、三氟乙酸（名称或化学式，如 CH₃COOH、CF₃COOH），萤石（CaF₂），冰（冰的结构片段）。
- V₃Si、LaBeH₈ 归入晶体类，问题里提到时按问题打开。
- 屏蔽：乙酸乙酯、甲酸甲酯、乙酸钠、醋酸钠、冰晶石、冰水、冰糖、冰点、冰箱，不会被认成乙酸、甲酸或冰。
- 新加的名称只用来认物质、打开模型，检索分词仍按原来的方式处理。
- 「乙酸根」「甲酸乙酯」「三氟乙酸钠」这类后面接着根、盐、酯、酐的词，说的是羧酸根、盐或酯，不认作游离酸。
- 中文方括号【】与英文方括号一样按配合物处理，括号里的配体不再算作问题中的物质。

## 一句话比较两种以上羧酸
问题里同时出现两种以上羧酸、并且问的是酸性强弱（含酸性、强酸弱酸、pKa、Ka、电离等字样，如「三氟乙酸为什么比乙酸酸性强？」）时；问杂化、沸点等其他性质时不切换，打开 AXIOM 的「羧酸的酸性」演示：pKa 条形图把问到的几种酸排在一起，停在问到的酸里排得最靠后的那一步（丙酸、乙酸、甲酸、氯乙酸、二氯乙酸、三氯乙酸、三氟乙酸依次为第 1～7 步），三维显示那一种；点条形可以切换看另一种的三维模型。只问一种酸时仍打开那种酸的模型。按问题打开时，图层过滤现在保留目录里存在的高亮步骤。npm test 26/26，浏览器联动测试加了这一项，在 Chromium 下通过。

## 审查后的修改（2026-11-12）
- 羧酸根、盐、酯不再被认作游离酸；中文方括号按配合物处理（见上）。
- 多种羧酸只在问酸性时打开 pKa 演示。
- 问共轭碱、羧酸根、失去 H⁺ 时打开的仍是酸的模型，状态栏会注明「原酸示意，共轭碱是失去 H⁺ 后的羧酸根」。
- E-CRYS-11 的正确理解补上了「立方（直角）晶胞」的前提，并说明六棱柱等要按实际共用情况算。
- 嵌入的 AXIOM 里两张卡片的补充讲解改正：「均摊法与晶胞计算」的非立方体积写清夹角条件（六方晶胞 V = (√3/2)a²c）；「分子的极性」补上 XeF₂、XeF₄ 有孤电子对但结构对称、是非极性分子，并说明「化合价绝对值等于价电子数」的规律不能反过来用。
- 回退请求也会重新计时；换成没有模型的结果后，迟到的回执不再改写状态（新增 tests/bridge.test.mjs）。
- 浏览器测试改为等到本次回执，不再靠固定等几秒。
- tests/report.mjs 标注为 1.1 版历史文件。
- npm test 28/28 通过；浏览器联动测试在 Chromium 下用短等待加轮询通过。

## 第二轮审查后的修改（2026-11-12）
- 识别物质更严：NO₂⁺、不带电荷的 NO₂ 不再当成亚硝酸根；ASCII 写法的电荷（NO2-、SO42-、NH4+）能认，Ca2+、Fe3+ 这类单原子离子不算模型物质。
- 乙酸苯酯等酯不再让「苯」被认出来；氟乙酸、溴乙酸、氨基乙酸、2-氯丙酸等取代酸不当成母体酸；苯甲酸、苯酚等屏蔽词和羧酸衍生物记作「未知物质」，比较题仍算两种物质。
- sp²、sp³、3d⁶4s² 这类小写记号，VSEPR、I₁、族序数等不再当成物质；I₂ 可能是碘单质，保留。
- 题干同时出现 LaBeH₈ 和其中的 BeH₈ 单元、或冰和水分子时，按 LaBeH₈、冰处理。
- 方法卡片只让给同类物质（分子方法卡让给分子、晶体方法卡让给晶体），原子光谱卡不再让位；让位时带上对应图层（杂化、极性、大π键）。
- pKa 的下标写法、「共轭碱」也算问酸性；讲共轭碱的卡片打开乙酸模型时，无论问题怎么问都显示「原酸示意」。
- 同为羧酸时，本地错因匹配不再因为错因里举的是另一种酸而漏掉。
- 桥接层：连续两次打开时，上一次的迟到回执被丢弃。浏览器测试补上漏掉的回执清零。
- 知识库：E-DELOC-09 改成按 N 成几条 σ 键、有没有参与双键来区分吡啶型和吡咯型（N 上连碳的吡咯型也适用）。
- 嵌入的 AXIOM 卡片补充讲解改正 8 处：大 π 键记号统一为 Πₘⁿ（下标原子数、上标电子数）；HNO₃ 补上按带电结构式数电子的说法；碳连两个双键为 sp；OCN⁻ 的算法说明电荷已体现在 O⁻ 上；低温石英的手性说法与 12 元环不再矛盾；两点间距离公式补上平方和与「三个夹角都是 90°」的前提；六棱柱晶胞补全底面棱 1/4、侧面 1/2；分数坐标说明顶点「只记一个 (0,0,0)」的前提。
- npm test 30/30 通过（新增两条）；浏览器联动测试在 Chromium 下通过。
